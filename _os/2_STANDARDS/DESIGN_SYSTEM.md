# DESIGN_SYSTEM — дизайн Ellen Soul (пріоритет №1)
`v1.0 · 2026-07-06 · owner: Claude(CTO)` · luxury-естетика = частина продукту

## 1. Brand Identity
Преміальний езотеричний бренд: тепле «слонове» тло, пісочно-золоті акценти, серифна типографіка, мʼякий рух. Тон: містично, тепло, дорого; БЕЗ кислотних кольорів, кітчу й «хеловінщини».

## 2. Токени (Single Source of Truth — ДВА синхронні місця)
Канонічні значення живуть у **`tailwind.config.ts`** (палітри cream/sand/warm/gold, шрифти, display-розміри, spacing) і продубльовані в **`app/**/globals.css` `:root`** (для чистого CSS). **Правило синхрону:** зміна токена = зміна в ОБОХ файлах одним комітом. Перевірка перед PR: `grep -n "#D4A853" tailwind.config.ts app/**/globals.css` — значення збігаються.

### Палітра (канон — tailwind.config.ts)
- `cream.50-500` (#FDFBF7→#C9B890) — тло, поверхні
- `sand.100-500` (#F2EBD9→#A88A5A) — картки, розділювачі
- `warm.900-400` (#1C1512→#9B7A52) — текст, темні секції (warm-900 = основний текст)
- `gold.300-600` (#E8C98A→#9A6E28) — акценти, CTA, актив (gold-400 #D4A853 = головний акцент)
- `--muted` #7A6A58 — вторинний текст; `--radius` 0.75rem — базовий радіус
**Заборонено** кольори поза палітрою. Новий відтінок = спершу розширити токени (обидва файли).

### Типографіка
- **Serif/Display:** Cormorant (var `--font-cormorant`) — заголовки, фірмові акценти, курсивні `<em>`.
- **Sans/Body:** Jost (var `--font-jost`) — усе інше.
- Завантаження — **лише `next/font`** у `app/layout.tsx`. Google Fonts CDN / @import — **заборонено** (коментар у globals.css — це правило).
- Display-розміри: `display-2xl/xl/lg` (clamp-токени з config) — тільки для hero/розділів.

### Інше
- Тіні/градієнти: використовувати наявні (`bg-grain` текстура, gradient-radial). Grain — фірмовий шар, не прибирати.
- Радіуси: `--radius` (0.75rem) базовий; різкі кути — лише свідомим рішенням.
- Рух: **framer-motion**; мʼякі появи (opacity/translate), 0.4-0.8s; БЕЗ агресивних bounce. Поважати `prefers-reduced-motion`.
- Теми: `next-themes` (darkMode: class) — зміна компонентів перевіряється в обох темах, якщо сторінка їх підтримує.

## 3. Компоненти
- Основа — **Radix UI** (accordion/dialog/tabs/scroll-area) + **CVA** (class-variance-authority) для варіантів. Нову варіацію кнопки/картки — через CVA-варіант існуючого компонента, НЕ новий клас-клон.
- Компоненти живуть у `components/`; сторінкові — поряд зі сторінкою лише якщо одноразові.
- Іконки — **lucide-react** тільки.

## 4. Що НЕ можна
- ❌ Кольори/шрифти поза токенами; ❌ Google Fonts CDN; ❌ нові UI-бібліотеки без ADR; ❌ inline-стилі для кольорів/розмірів; ❌ дублікати компонентів (спершу пошукай у `components/`).

## 5. Правило консистентності (імпорт GrandKeram, оплачено 3 повторами)
- **Та сама дія = той самий варіант кнопки на всіх сторінках.** Одна primary-CTA на блок.
- **Будь-який дотик до UI = відкритий цей файл + ПОБАЧЕНИЙ рендер кожної зміненої сторінки** (усі 3 мови, якщо текст; обидві теми, якщо стилі) ДО деплою. DOM-проба ≠ «бачив».
- Скріни змінених сторінок поруч — щоб зловити розбіжності.

## 6. Workflow нової сторінки
1. Скопіювати структуру найближчої сторінки того ж типу (layout/[lang]).
2. Тільки токени; тексти одразу в `translations.ts` ×3 мови.
3. `npm run lint && npm run build` → прев'ю (десктоп+мобільний) → deploy.
