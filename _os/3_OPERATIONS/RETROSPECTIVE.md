## Імпортовані уроки GrandKeram (оплачені там — тут безкоштовні)
- **Трешинг при відмові:** міняв підхід замість діагнозу причини. → відмова → діагноз → мінімальна зміна.
- **Передчасне «готово»** до валідації. → «готово» каже користувач.
- **Ітерації наосліп** без петлі перевірки. → спершу спосіб перевірки.
- **«Мінімум, доробю коли помітять»** — системний патерн, коренева причина болю. → повний набір одразу (СТАНДАРТ ЯКОСТІ).
- **UI без відкритого стандарту і без побаченого рендера** (3 повтори за день!). → дотик до UI = стандарт відкритий + скрін КОЖНОЇ зміненої сторінки.
- **Секрет у клієнтському коді** (Telegram-токен) = скомпрометований секрет. → server-only env, пожежне відкликання.
- **Відкрита база без правил доступу** = публічний витік клієнтів. → RLS обовʼязковий з першої міграції (тут уже так — тримати).
- **Док ≠ реальність** дрейфують за добу. → закрив задачу — торкни стандарт.
- **Гіпотеза ≠ факт:** діяти лише після підтвердження даними (index-bloat був спростований — дія за гіпотезою нашкодила б).
- **Файл поза роутером = двійник** (розщеплена історія RETROSPECTIVE). → новий файл одразу в роутер CLAUDE.md.
- **Постдеплой перевіряє доступність, не свіжість** → після деплою контролювати КОНТЕНТ зміненого.
